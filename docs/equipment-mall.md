# 工位与设备指令

当前工位系统统一通过`/我的工位`、`/工位游戏`、`/帮助 工位`和小游戏“我的养成”管理。旧`/工位商店`、`/装备商店`、`/装备商城`、`/我的装备`、`/工位帮助`不再回复；历史数据库与必要装卸兼容路径保留。

## 当前指令

- `/我的工位`：只显示环境、设备名称和各自日收益、工位合计日收益。
- `/工位游戏`：直接发送小游戏卡片或网页入口，不附带工位概览。
- `/帮助 工位`：查看玩法和操作，小游戏问号弹窗与它保持一致。
- `/工位背包`：查看已拥有的环境和设备。
- `/工位收益表`：查看五级整套环境收益、十档设备收益及升级费用。
- `/升级 鼠标`、`/升级 电脑`：提升已购买进度对应设备的一档。
- `/升级 环境`：四件设备已购买至当前环境升级款后，整体迁入下一环境。
- `/装备 鼠标 2-1`、`/装备 环境 2`：免费切换已拥有环境及其设备档位。

设备显示编号为2电脑、3显示器、4键盘、5鼠标，环境显示编号为1；数据库中的历史部件编号仍由服务端映射，玩家优先使用名称指令。

配件随对应环境自动获得，不单独购买，也不独立展示群聊商店。设备升级、环境迁移保留职级及余额门槛；最高已购买等级和当前展示装备分别记录。设备未装备最高档或切回旧环境不会减少购买资格。收益按当前实际装备计算。

每个群的消息回执和网页操作请求都具有防重复处理逻辑，报价变化时拒绝旧支付，不通过浏览器传入金额更新余额。启用每日结算后，由后端按北京时间日期发放，保留每日回执和流水。

完整规则见[工位系统](workstation.md)，数值与回本测算见[价格说明](workstation-pricing.md)，平台发布步骤见[小游戏构建与发布](gamefy-workstation-publishing.md)。
